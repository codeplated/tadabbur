## Tafsir — Bayan ul Quran (Dr. Israr Ahmad)

آیت 9{ قَالُوْا بَلٰی قَدْ جَآئَ نَا نَذِیْـــرٌ 5} ”وہ کہیں گے کیوں نہیں ! ہمارے پاس خبردار کرنے والا آیا تھا“ { فَکَذَّبْنَا } ”لیکن ہم نے اسے جھٹلا دیا“ { وَقُلْنَا مَا نَزَّلَ اللّٰہُ مِنْ شَیْئٍ } ”اور ہم نے کہا کہ اللہ نے کوئی شے نہیں اتاری۔“ ہم نے اپنے رسولوں علیہ السلام سے کہا تھا کہ اللہ تعالیٰ نے تمہاری طرف کوئی کتاب وغیرہ نہیں بھیجی ‘ بلکہ ہم نے تو انہیں یہاں تک کہہ دیا تھا کہ : { اِنْ اَنْتُمْ اِلَّا فِیْ ضَلٰلٍ کَبِیْرٍ۔ } ”تم تو کھلی گمراہی میں مبتلا ہوگئے ہو۔“
